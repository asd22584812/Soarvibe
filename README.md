# SOARVIBE

AI 旅遊規劃 Web App（手機版介面）。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。

Gemini API Key 可在 App 內設定，或於瀏覽器 Console 執行：

```js
localStorage.setItem("SOARVIBE_GEMINI_API_KEY", "您的金鑰")
```

Google Maps 金鑰請在本機 `index.html` 的 `GOOGLE_MAPS_API_KEY` 填入，勿提交到 GitHub。
